# 궤도 탈출

브라우저에서 20초 동안 낙하물을 피하는 미니게임. 로그인이나 외부 API가 필요하지 않습니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 정적 서버로 `dist/`를 제공하세요. 키보드 좌우 화살표/A·D 또는 화면 버튼으로 한 칸 이동합니다. 충돌 3회면 실패, 20초 생존이면 성공입니다.

## 저장과 접근성

완주 횟수와 화면 효과 선택은 이 브라우저의 localStorage에 저장됩니다. 기록 초기화 버튼과 손상된 저장값 자동 복구가 있습니다. 화면 효과를 꺼도 규칙과 난이도는 같습니다.

## 검사 기록

`node check.mjs`로 좌우 경계, 성공·실패 후 재시작, 20회 자동 시뮬레이션, 가상 시간 10분 실행을 검사했습니다. 낙하 간격만 바꿔 850ms는 성공 2/10회·평균 13.1초, 1000ms는 성공 3/10회·평균 16.0초여서 1000ms를 채택했습니다. 실제 브라우저 10분 연속 실행과 시크릿 창 공개 URL 검사는 배포 뒤 별도로 해야 합니다.
